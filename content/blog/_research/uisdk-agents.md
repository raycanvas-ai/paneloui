## 0. Verified facts about Vercel's UI SDK (checked 2026-11-24)

| Fact | Value | Source |
|---|---|---|
| What it is | "A library of behaviors for agents to build and drive the next generation of user interfaces." Keyboard nav, focus, selection, dismissal, popups, drag and drop and their ARIA live in `@ui-sdk/core`. | https://github.com/vercel-labs/ui (README), https://ui-sdk.dev |
| Docs intro | "UI SDK is a library of behaviors, like popups, lists and typeahead, that your agent puts together into components." "UI SDK is in beta, so some APIs may still change." | https://ui-sdk.dev/docs |
| Who | Vercel Labs; repo `vercel-labs/ui`, created 2026-10-26. npm maintainer account on `@ui-sdk/react` is `shadcn`. | GitHub API; https://registry.npmjs.org/@ui-sdk%2Freact |
| License | Apache-2.0 | GitHub API, npm |
| Packages | `@ui-sdk/core` + adapters `@ui-sdk/react`, `@ui-sdk/vue`, `@ui-sdk/svelte`, `@ui-sdk/solid`, `@ui-sdk/web` | README; GitHub releases |
| Version | `0.1.0-beta.16` (published 2026-11-23). First npm publish 2026-11-12. **BRIEF.md says beta.2: outdated, fix before writing.** Write "beta" without a number, or re-check. | npm registry |
| Install | `npm install @ui-sdk/react @ui-sdk/core`; React 19 or newer. Agent skill: `npx skills@latest add vercel-labs/ui --skill ui-sdk` | README; https://ui-sdk.dev/docs |
| Building blocks | `definePrimitive` (state, api, slots) + `createParts` (from `@ui-sdk/react/primitive`) renders Root/Input/etc. Behaviors like `createPopup`, `createSelection`, `createTypeahead`, `createRovingFocus`, `createListbox`, `createVirtualizer`; site says 50+ behaviors. | README; https://ui-sdk.dev |
| Agent bridge | `import { createAgent } from "@ui-sdk/react/agent"`; `agent.snapshot()` lists components, state and available actions (e.g. `{component:"input", label:"Project name", value:"Apollo", actions:["setValue","clear"]}`); `agent.act({ steps: [{ ref: "Project name", action: "setValue", args: ["Atlas"] }] })`; also `query`. Changes go through the component's API and change callback, not DOM edits. | https://ui-sdk.dev/docs/agents |
| Telling agent from user | Change callbacks receive `source: "agent"` and can cancel the change. | https://ui-sdk.dev/docs/agents |
| Permissions | `createAgent({ allow })`: return `true`/`false` or a `Promise<boolean>` (bridge waits; default 5-minute timeout, configurable via `timeout`). Refusal stops `act` with `ok: false`; earlier steps stay applied. | https://ui-sdk.dev/docs/agents/connect-an-agent/permissions |
| Confirm-first controls | `data-agent-confirm="Charges $20 to your card for 1,000 credits"`. Without `allow`, pressing it fails with "Needs a person". With `allow`, the sentence arrives as `step.confirm`. Docs warn an `allow` that returns `true` without checking `step.confirm` approves on the person's behalf. Docs never use the word "destructive". | same |
| WebMCP | `registerTools(agent, { allow })` registers tools via `document.modelContext.registerTool`; no-op in browsers without it. Tools: `snapshot` (read-only), `act` (consequential, browser may ask the person), `query` (read-only); all flagged as handling untrusted content. | https://ui-sdk.dev/docs/agents/connect-an-agent/webmcp |
| Benchmark (vendor-run) | Repo `benchmarks/agent`: one "project settings" task, medians of 3 runs, Sonnet via Claude Code, 2026-11-15, all runs correct. React: Base UI + browser tools 17 calls / 291.7k tokens / 53 s / $0.139; Ark UI 19 / 330.9k / 65 s / $0.144; ui-sdk + browser tools 17 / 294.1k / 56 s / $0.140; **ui-sdk + agent tools 7 / 69.5k / 31 s / $0.044**. README: "With browser tools, the ui-sdk screen takes about as much as the others. The difference comes from the agent tools." Vue and Svelte show the same pattern (Reka UI, Bits UI). | https://github.com/vercel-labs/ui/tree/main/benchmarks/agent |
| Docs pages (for linking) | /docs, /docs/components, /docs/agents, /docs/agents/build-with-an-agent, /docs/agents/skills, /docs/agents/connect-an-agent (+ /guide, /your-components, /permissions, /observe-changes, /history-and-undo, /run-on-your-server, /webmcp, /reference) | https://ui-sdk.dev/docs/agents |
| Traction (snapshot, volatile) | GitHub 6,964 stars / 246 forks; HN "Show" story 9 points, 0 comments (2026-11-12, https://news.ycombinator.com/item?id=50472545); Product Hunt "UI SDK by Vercel", 88 points, #16 day rank, Guillermo Rauch listed as maker (https://www.producthunt.com/posts/ui-sdk-by-vercel). npm shows 654k weekly downloads for `@ui-sdk/react` (Nov 16-22): **do not cite**, a 12-day-old beta with that count is likely transitive/CI installs. | GitHub API, HN Algolia, PH, npm API |
| Coverage | InfoQ, "Vercel Releases UI SDK for Agents to Compose UI from Reusable Behaviors", Daniel Dominguez, 2026-11-18 (cites beta.1, 50+ unstyled components, React 19+, "Vercel has not said whether shadcn/ui will be rebuilt on UI SDK"). MarkTechPost 2026-11-13. | What it is NOT | **Vercel AI SDK** = npm `ai` (latest 7.0.181), "build apps like ChatGPT, Claude, Gemini… with a single interface for any model", docs at ai-sdk.dev. **AI SDK UI** = its client hooks (`useChat`) for chat and generative UI. **AI Elements** = shadcn-registry chat components for the AI SDK (elements.ai-sdk.dev). UI SDK is none of these: it calls no model. | https://registry.npmjs.org/ai, https://ai-sdk.dev/docs/ai-sdk-ui, https://elements.ai-sdk.dev |
