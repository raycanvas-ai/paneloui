# Keyword research: Tailwind CSS v4, theming and front-end craft

Cluster: Tailwind CSS v4 theming, tokens, dark mode, tailwind-merge, RTL, focus, scroll fade / progressive blur, React Aria, copy-paste vs npm, registries, llms.txt, AGENTS.md.
Date: 2026-11-24. Method: Google autocomplete (curl, ~170 seeds incl. question/modifier expansions, 622 relevant suggestions after noise filter), then 34 SERP checks via WebSearch (top ~10-20 results each).

**Honesty notes**
- No search-volume data (no paid tools). Autocomplete presence = real demand exists; depth of suggestions (e.g. "tailwind v4 dark mode" has 8+ variants) is the only volume proxy.
- WebSearch is not a Google exact-match SERP. "Top domains" are the domains that recurred, not verified Google positions.
- KD = L/M/H judged from: official doc in results? authority of the rest? how fresh / v4-correct the ranking pages are? thin pages (agent-skill directories, mirrors, v3 docs) ranking = weakness.

**SERP pattern worth knowing (applies to the whole cluster)**
1. **v3-era pages still rank for v4 queries**: v3.tailwindcss.com (dark-mode, colors, ring-width, font-size), v2.tailwindcss.com, tailwind-merge v1.9/v2.0 docs, Subframe's v3 `tailwind.config.js` guides, the `tailwindcss-rtl` plugin. These answer the wrong version.
2. **Agent-skill directories rank with thin content**: skills.sh, tessl.io, skillsmp.com, lobehub, smithery, sharedcontext.ai show up on almost every v4 query (dark mode, design tokens, design system, RTL, focus). They are scraped SKILL.md files, not explanations. A real explainer beats them.
3. **Mintlify auto-mirrors of the Tailwind docs** (mintlify.com/tailwindlabs/tailwindcss/...) rank next to the real docs.
4. **dev.to dominates** troubleshooting queries with first-person "gotcha" posts. The canonical answer often lives only in a GitHub Discussion.
5. Official tailwindcss.com docs often did not surface for the troubleshooting phrasing ("not working", "vs", "what is @theme inline"). They do surface for reference phrasing ("custom utility", "upgrade guide", "mask-image").
